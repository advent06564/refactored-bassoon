# Refactored Bassoon

[![CI](https://github.com/advent06564/refactored-bassoon/actions/workflows/ci.yml/badge.svg)](https://github.com/advent06564/refactored-bassoon/actions/workflows/ci.yml)

A social media manager script to access multiple social media manager sites simultaneously.

## Features

- Multi-platform social media management
- Automated task execution
- Configuration-driven workflow via `config.json`

## Getting Started

### Prerequisites

- Python 3.x

### Run

```bash
git clone https://github.com/advent06564/refactored-bassoon.git
cd refactored-bassoon
python main.py
```
